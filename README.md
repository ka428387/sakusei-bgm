# さく井業BGM生成器

井戸を掘りながら音楽が生まれる、ブラウザで動く1ファイルの掘削シミュレーターです。
地層が変わるとスケール・音色・テンポ感が変わり、そのまま BGM になります。時間は約5,000倍速。

## 遊びかた

1. **掘削開始** を押す（同時に音が鳴りはじめます）
2. **泥水ポンプ** を入れる — 循環がないと孔壁が保てず、深さ4mから先に進めません
3. **送水量** を調整する — 砂れき層では 225 L/min 以上ないと逸泥して掘進がほぼ止まります
4. 回転数はテンポ、送水量は打撃音の抜けと残響量に効きます
5. 破砕帯の裂か水に当たれば **出水**、所定深度でケーシングを建て込んで井戸の完成です

### トラブル

深く掘るほど、粘土層・砂れき層・破砕帯ほど事故が起きます。送水量を上げておくと確率が下がります。

- **孔壁崩壊** — 数メートル埋まり、掘り直しになります
- **ビットの固着** — ジャーリングで抜けを試みます。**ジャーリング** ボタンを叩くと復旧が早まり、成功率も少し上がります
- 抜けなかった場合はセメントで孔を埋め、少し上から掘り直し。古い孔と残置ビットは地層図に残ります

対処はすべて自動で進みます。プレイヤーにできるのは予防だけです。

## 技術メモ

- 依存ライブラリなし。HTML/CSS/JS 1ファイル、ビルド不要
- 音は Web Audio API でその場で合成（音源ファイルなし）。地層ごとに5音音階・ルート音・音色を持たせ、16分音符グリッドで先読みスケジューリングしています
- スケジューラは `setInterval`、描画は `requestAnimationFrame` に分離（非表示タブで rAF が止まるため）
- 水脈の深さは起動ごとにランダムなので、毎回ちがう井戸になります
- `prefers-reduced-motion` に対応

## 動作環境

Chrome / Safari / Firefox の最新版。iOS では端末のサイレントスイッチが入っていると音が鳴りません。
