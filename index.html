井戸ビート

井戸を掘ると、地層が音楽になる。掘り方を選んでください。

音が出ます。音源ファイルは使わず、その場で合成しています。

ROTARY

ロータリー編

ビットを回して削る。泥水を循環させて孔壁を保ちながら、岩盤の奥の破砕帯まで掘り下げます。

深さ 130〜180m 時間 約5,000倍 この工法で掘る →
PERCUSSION

パーカッション編

綱で吊った工具を落として砕く、昔ながらの綱掘り。掘りカスはベーラーでさらい、その間が間奏になります。

深さ 30〜70m 時間 約1,000倍 この工法で掘る →
共通のしくみ
音は Web Audio API でその場で合成しています。地層ごとに音階・ルート音・音色を持たせてあるので、 掘り進んで層が変われば曲が変わります。水脈の深さは掘るまで分かりません。水が出たら、そこで井戸は完成です。
深く掘るほど事故が増えます。孔壁が崩れれば、埋まった分を掘り直し。ビットが地層に喰われたら、 掘進は止まり、気づくまで唸りが鳴り続けます。ジャーリングのボタンで抜いてください。時間制限はありませんが、 叩くほどワイヤーに無理がかかり、切れればビットごと孔を失います。そのときは孔もビットも地中に置いたまま 埋め戻し、横に寄って一からの掘り直しです。捨てた孔と残置ビットは地層図にそのまま残ります。
手元のつまみは、ロータリー編が回転数・送水量・泥水ポンプ、パーカッション編が打撃数・ストローク・ベーラー。
