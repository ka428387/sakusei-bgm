さく井業BGM生成器

井戸を掘ると、地層が音楽になる。

音が出ます。ブラウザだけで動き、音源ファイルは使っていません。

掘り方を選んでください。同じ地面でも、工法が変われば鳴る音が変わります。

共通のしくみ

音は Web Audio API でその場で合成しています。地層ごとに音階・ルート音・音色を持たせてあるので、 掘り進んで層が変われば曲が変わります。水脈の深さは掘るまで分かりません。
深く掘るほど事故が増えます。孔壁が崩れれば埋まった分を掘り直し、ビットが地層に喰われれば ジャーリングで抜く。抜けなければ孔を捨てて、少し上から掘り直しです。捨てた孔と残置ビットは 地層図にそのまま残ります。
